# Система управления семинарами

Консольное приложение для учёта семинаров, регистрации участников
и формирования расписания докладов.

## Возможности
- просмотр, добавление и поиск семинаров;
- регистрация участников с проверкой свободных мест;
- запрет повторной активной регистрации участника на один семинар;
- отмена регистрации (без удаления записи — только смена статуса);
- отменённая регистрация освобождает место для нового участника;
- добавление докладов и формирование расписания семинара;
- хранение данных между запусками в JSON-файлах.

## Целевая аудитория
Организаторы семинаров и участники, которым нужно регистрироваться
на мероприятия и видеть программу докладов.

## Предметная область
Пользователь может зарегистрироваться на семинар на определённую дату.
Один семинар не может принять больше участников, чем задано лимитом мест.
Отменённая регистрация не блокирует место и позволяет зарегистрироваться
другому участнику.

## Основные сущности

### Seminar — семинар
Объект `Seminar` представляет мероприятие, доступное для регистрации.

Основные атрибуты:
- `id` — уникальный идентификатор семинара;
- `title` — название;
- `date` — дата проведения;
- `max_participants` — лимит участников.

Основные методы:
- `is_available_for()` — проверка наличия свободных мест при заданном
  числе регистраций;
- `__str__()` — строковое представление семинара.

### Participant — участник
Объект `Participant` представляет участника семинаров.

Основные атрибуты:
- `id` — уникальный идентификатор участника;
- `name` — имя;
- `email` — адрес электронной почты.

Основные методы:
- `__str__()` — строковое представление участника;
- `from_data()` — создание участника из данных JSON.

### Registration — регистрация
Объект `Registration` представляет регистрацию участника на семинар.

Основные атрибуты:
- `id` — уникальный идентификатор регистрации;
- `seminar` — объект `Seminar`;
- `participant` — объект `Participant`;
- `is_cancelled` — признак отмены регистрации.

Основные методы:
- `cancel()` — отмена регистрации;
- `__str__()` — строковое представление регистрации.

### Talk — доклад
Объект `Talk` представляет доклад в программе семинара.

Основные атрибуты:
- `id` — уникальный идентификатор доклада;
- `seminar` — объект `Seminar`, к которому относится доклад;
- `title`, `speaker`, `start_time`, `duration_minutes`.

Основные методы:
- `__str__()` — строковое представление доклада.

## Основные операции

### Работа с семинарами
- добавление семинара;
- поиск семинара по названию;
- сортировка семинаров по дате;
- просмотр списка семинаров.

### Работа с участниками
- регистрация нового участника (создаётся при первой регистрации по email);
- поиск участника;
- просмотр списка участников.

### Работа с регистрациями
- создание регистрации с проверкой доступных мест;
- запрет повторной активной регистрации на тот же семинар;
- отмена регистрации;
- просмотр списка регистраций.

### Работа с докладами
- добавление доклада к семинару;
- формирование расписания докладов, отсортированного по времени.

## Хранение данных
Данные приложения хранятся в JSON-файлах:
- `data/seminars.json`;
- `data/participants.json`;
- `data/registrations.json`;
- `data/talks.json`.

При загрузке данные из JSON преобразуются в объекты `Seminar`,
`Participant`, `Registration` и `Talk`. При сохранении объекты
преобразуются обратно в данные. Для связи регистрации с семинаром
и участником в `registrations.json` используются их идентификаторы
`seminar_id` и `participant_id`; аналогично `talks.json` хранит
`seminar_id`.

## Назначение модулей

### `main.py`
Точка входа в приложение. Отвечает за запуск, отображение меню,
получение данных от пользователя и организацию пользовательских сценариев.

### `models/seminars.py`
Содержит класс `Seminar` и функции работы с коллекцией семинаров.

### `models/participants.py`
Содержит класс `Participant` и функции работы с коллекцией участников.

### `models/registrations.py`
Содержит класс `Registration` и функции работы с коллекцией регистраций.

### `models/talks.py`
Содержит класс `Talk` и функции работы с докладами и расписанием.

### `storage.py`
Отвечает за загрузку и сохранение данных. Выполняет преобразование:
JSON → объекты Python и объекты Python → JSON.

### `utils.py`
Содержит вспомогательные функции:
- `input_int()` — безопасный ввод целого числа;
- `input_date()` — безопасный ввод даты.

### `tests/`
Содержит автоматизированные тесты проекта.

## Требования
- Python 3.x;
- pytest;
- flake8.

Установка зависимостей:
```
pip install -r requirements.txt
```

## Запуск приложения
```
python main.py
```

## Тестирование
Для запуска автоматизированных тестов выполнить:
```
pytest -v
```
Тесты проверяют:
- создание и работу объектов `Seminar`, `Participant`, `Registration`
  и `Talk`;
- методы классов;
- операции с семинарами (создание, поиск);
- создание и отмену регистраций;
- правило доступности мест на семинаре;
- формирование расписания докладов.
