# Система управления семинарами

## Назначение
Приложение предназначено для организации научных и учебных семинаров:
регистрации участников, планирования докладов и формирования расписания
мероприятий.

## Целевая аудитория
Организаторы семинаров (преподаватели, руководители научных кружков),
участники семинаров и докладчики.

## Предметная область
Организация и проведение семинаров: учёт участников, докладов и
временных слотов, на которые они распределяются.

## Основные сущности
- Семинар
- Участник
- Доклад
- Расписание

## Основные функции
- Регистрация участника на семинар с проверкой наличия свободных мест
- Добавление доклада в программу семинара с указанием докладчика
- Формирование расписания докладов по датам и времени

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
